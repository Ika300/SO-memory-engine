# Public / Private Boundary Draft

This is a planning document for future release decisions. It is not a public promise.

## Public candidate

The public Engine repository may include:

- basic MemoryEngine
- basic ContextPack
- basic examples
- basic tests
- documentation
- local-only demos

## Private / Pro candidate

A future Pro Pack may include:

- polished chat app template
- agent memory template
- note app memory template
- advanced Context Pack recipes
- prompt integration guide
- commercial integration guide
- debugging guide
- failure diagnosis guide
- private advanced examples

## Boundary principle

Public release should prove the Engine is real and useful.
Pro material should save implementation time and provide practical integration patterns.

## Not decided yet

The Engine must be developed and tested before deciding final public/private separation.
