# Free Extractor Limits

SO Extractor Free is an entry path, not the commercial parser.

It is useful for:

- trying SO Memory Engine with conversation-like logs
- understanding MemoryUnit shape
- testing validation and export flow
- building small local demos

It is not designed for:

- high-accuracy natural-language parsing
- production extraction quality
- robust canonical memory generation
- deep relation extraction
- span-level source mapping
- domain-specific interpretation

The rule extractor is intentionally transparent. It should not pretend to be smarter than it is.
